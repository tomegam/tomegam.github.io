# Zhen Gao’s academic homepage

The site runs on GitHub Pages from the root of the `main` branch. It uses plain HTML and CSS.

- `index.html` contains the biography and photograph.
- `research.html` contains the papers, theses, talks, and attended events.
- `teaching.html` contains the courses and course materials.
- `files/` contains the PDFs hosted directly on GitHub Pages.
- `styles.css` controls the layout and typography.

To preview a change, open `index.html` in a browser. Commit the edited files to `main` to publish the update.

The research and teaching pages link directly to the PDFs in `files/`. The physics papers link to Google Drive.
